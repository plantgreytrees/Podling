# ARCH speech — enforced rules

- **ARCH-SPEECH-01** [decided] MUST carry a name's respelling on `SpokenTurn` as an optional model-facing text (`say_as: Option<String>`, skipped from serde when `None`), set only in `spoken()`, and MUST NOT overwrite `SpokenTurn.text` — check: `SpokenTurn` has the field with `skip_serializing_if = "Option::is_none"`; `spoken()` is the only writer — cite: crates/podling-core/src/stages/synthesize.rs:729
- **ARCH-SPEECH-02** [decided] MUST send `say_as` (falling back to `text`) as the wire turn's `text` in `wire_turns`, and nowhere else — check: `WireTurn.text` is built from `say_as.as_deref().unwrap_or(&text)` — cite: crates/podling-core/src/plugin/sidecar_tts.rs:290
- **ARCH-SPEECH-03** [decided] MUST NOT change the worker protocol (`PROTOCOL = 1`), the backends or `ADAPTER_VERSION` for pronunciation; the worker never sees the lexicon — check: no diff under `sidecars/tts/podling_tts/` for pronunciation work — cite: sidecars/tts/podling_tts/backends/__init__.py:23
- **ARCH-SPEECH-04** [decided] MUST keep `SpokenTurn::said()`, the speech check's expected text and the quotes on the original words; a respelling never reaches `Check::new` — check: `said()` reads `text`, never `say_as` — cite: crates/podling-core/src/plugin/tts.rs:75
- **ARCH-SPEECH-05** [decided] MUST match lexicon names whole-word and case-sensitively, longest name first, in the turn's own text only (not backchannel text); a turn with no match MUST get `say_as = None`, so its chunk key is unchanged — check: unit tests for word boundary, case, overlap order and the unchanged key of a turn without names — cite: crates/podling-core/src/lexicon.rs:131
- **ARCH-SPEECH-06** [decided] MUST merge the user-level lexicon `pronounce.toml` (beside the `sidecars.toml` in use, by default in `~/.config/podling/`) with the episode's `[tts.pronounce]`, the episode entry winning per name; the user file is located by the CLI/pipeline like `sidecars.toml` and never named by the episode — check: merge test where both define a name — cite: crates/podling-core/src/pipeline.rs:321
- **ARCH-SPEECH-07** [decided] MUST put the episode lexicon inside `TtsConfig::Sidecar` as `pronounce` (default empty), so an episode without `[tts]` is unchanged, and MUST bump `SCHEMA_VERSION` and refresh the schema snapshot — check: schema snapshot diff shows only the new optional field; `SCHEMA_VERSION` incremented — cite: crates/podling-types/src/episode.rs:603
- **ARCH-SPEECH-08** [superseded by ARCH-SPEECH-18] MUST accept a lexicon entry as `Name = "say"` or `Name = { say = "...", heard = ["..."] }` (untagged), rejecting an empty name, an empty `say` or an empty `heard` item at deserialisation — check: deserialisation tests for both shapes and each rejection — cite: crates/podling-types/src/episode.rs:402
- **ARCH-SPEECH-09** [decided] MUST apply `heard` variants to the transcript's words only, mapping each variant to the name's words before WER and quote matching — check: test where Whisper's variant scores 0 WER against the original name — cite: crates/podling-core/src/stages/verify_audio.rs:417
- **ARCH-SPEECH-10** [decided] MUST fold British/American spellings in `words()` with a built-in explicit word-pair table, applied to both reference and transcript; MUST NOT use suffix rules or a new dependency — check: `kilometres` vs `kilometers` scores 0 WER; `acre`, `genre` unchanged — cite: crates/podling-core/src/stages/verify_audio.rs:63
- **ARCH-SPEECH-11** [decided] MUST NOT bump `SynthesizeChunk::VERSION` or `TranscribeChunk::VERSION` for the lexicon or the spelling fold: keys change only through `say_as`, the expected text is unchanged, and `Check` is recomputed each run — check: warm rerun of an episode without lexicon hits every cache entry — cite: crates/podling-core/src/stages/synthesize.rs:299
- **ARCH-SPEECH-12** [decided] SHOULD log at `debug` which lexicon names were applied to each chunk — check: `tracing::debug!` naming chunk and names in `spoken()`'s caller — cite: crates/podling-core/src/stages/synthesize.rs:484
- **ARCH-SPEECH-13** [decided] MUST add `LicenseRef-Podling-Generated` to `VOICE_LICENCES` for self-designed clips; no other new licence ids — check: `VOICE_LICENCES` has exactly the three CC ids plus this one — cite: crates/podling-types/src/episode.rs:236
- **ARCH-SPEECH-14** [superseded by ARCH-SPEECH-19] MUST reject a voice with the generated licence when `<clip>.provenance.json` (model, weights commit, design prompt, seed, tool version) is missing next to the clip, checked where references are resolved against the episode directory — check: test with and without the provenance file — cite: crates/podling-core/src/stages/synthesize.rs:137
- **ARCH-SPEECH-15** [decided] MUST build voice design as an offline `uv` script under `scripts/voice_design/` using Qwen3-TTS VoiceDesign (Apache-2.0), one GPU model at a time, writing the clip, its transcript and its provenance; it MUST NOT be a sidecar or be run by the pipeline, and its packages MUST pass dependency-auditor — check: no pipeline or `sidecars.toml` reference to it; auditor report on its `pyproject.toml` — cite: scripts/voice_design/design.py:22
- **ARCH-SPEECH-16** [superseded by ARCH-STORY-02] MUST bump `PROMPT_VERSION` for any script-prompt change against repetitive banter — check: the prompt diff and the constant change in one commit — cite: crates/podling-core/src/plugin/llm.rs:34
- **ARCH-SPEECH-17** [decided] MUST NOT change the TTS model (`MODEL` in `qwen.py`) under this area's work; a swap is its own spike, gated on ≤ 7.0 GB peak VRAM — check: `MODEL` unchanged — cite: sidecars/tts/podling_tts/backends/qwen.py:26
- **ARCH-SPEECH-18** [decided] MUST accept a lexicon entry as `Name = "say"` or `Name = { say = "...", heard = ["..."] }` (untagged or a hand-written `Deserialize`), rejecting at deserialisation an empty name, a name with leading or trailing whitespace (`name != name.trim()`), an empty `say`, an empty `heard` item, and a table without `say` with an error naming `say` — check: deserialisation tests for both shapes and each rejection, each with its own message — cite: crates/podling-types/src/episode.rs:439
- **ARCH-SPEECH-19** [decided] MUST reject a voice with the generated licence when `<clip>.provenance.json` (model, weights commit, design prompt, seed, tool version, and the clip's blake3 content hash as lowercase hex) is missing next to the clip, or when the recorded hash does not match the clip's bytes, checked where references are resolved against the episode directory; the voice-design script writes the hash with the `blake3` Python package, which MUST pass dependency-auditor — check: tests with no provenance, a mismatched hash (rejected) and a matching hash (accepted); a Python/Rust provenance field-set test — cite: crates/podling-core/src/stages/synthesize.rs:138
