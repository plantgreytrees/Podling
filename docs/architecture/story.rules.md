# ARCH story — enforced rules

- **ARCH-STORY-01** [decided] MUST present the script request's ledger claims in first-appearance order (the lowest index in `ScriptInput.chunks` of any of the claim's evidence chunks, ties broken by claim id), in the request view only; the `Ledger` artifact keeps its claim-id order — check: unit test with claims whose id order differs from source order; `ledger.json` bytes unchanged — cite: crates/podling-core/src/stages/script.rs:187
- **ARCH-STORY-02** [decided] MUST version the script prompt and its input shape with a separate `SCRIPT_PROMPT_VERSION`, in the `script` stage's config fingerprint only; `PROMPT_VERSION` stays in `extract_claims` only, and a script-only change MUST NOT bump it — check: `extract_claims` key in `NO_NLI_KEYS` unchanged by a script prompt change; `script.rs` fingerprint names `SCRIPT_PROMPT_VERSION` — cite: crates/podling-core/src/stages/extract_claims.rs:98
- **ARCH-STORY-03** [decided] MUST bump `WriteScript::VERSION` with a history comment for any change to the stage's logic, and `FakeLlm`'s fingerprint `version` whenever its replies change — check: version line and history comment in the same commit as the logic change — cite: crates/podling-core/src/stages/script.rs:109
- **ARCH-STORY-04** [decided] MUST ask, in the script instructions, for a cold open, one through-line taken from `topic`, anecdote followed by reflection, the judged Contested claims as the turning point told as a dispute, and a closing reflection; MUST NOT weaken rules 1–5 (citations, status handling, quote placeholders, untrusted data, fixed cast) or remove `check_judged_claims_are_cited` — check: prompt diff keeps rules 1–5; existing `script.rs` tests pass unchanged — cite: crates/podling-core/src/stages/script.rs:34
- **ARCH-STORY-05** [decided] MUST use `topic` as the episode's angle; MUST NOT add an angle or focus field to `EpisodeSpec` without a new architecture decision backed by harness evidence that two topics on one ledger give near-identical cited-claim sets — check: no new `EpisodeSpec` field for angle — cite: examples/titanic/episode.toml:12
- **ARCH-STORY-06** [decided] MUST compute script quality metrics in a pure function in `crates/podling-core/src/script_metrics.rs` (no I/O, no provider): words / (150 × target_minutes), turns, quotes, citations, distinct cited claims over usable (non-Unsupported) claims, judged Contested claims cited, and unknown-citation count; covered by tests in the default `cargo test` run — check: unit tests over fixed scripts; no `LlmProvider` or file I/O in the module — cite: crates/podling-core/src/script_metrics.rs:42
- **ARCH-STORY-07** [decided] MUST run live script evaluation as an `#[ignore]` test in `crates/podling-core/tests/script_eval_live.rs` that panics (never returns early) when its environment variable is unset, loads a saved run's artifacts, calls `WriteScript::run` directly (bypassing the cache) N times through an attempt-counting `LlmProvider` wrapper, and prints a per-run table and a summary built from `script_metrics` — check: test reads an env var and panics without it; no `DiskCache` use — cite: crates/podling-core/tests/script_eval_live.rs:43
- **ARCH-STORY-08** [decided] MUST NOT start the act writer unless the harness, on the default local model and against a baseline recorded in the plan, shows for the arc prompt a mean word ratio below 0.70, an eventual pass rate below baseline, or more unknown-citation rejections than baseline — check: the plan records the baseline and arc tables before any `act_plan.rs` code — cite: docs/architecture/story.rules.md:18
- **ARCH-STORY-09** [decided] If built, the act plan MUST be computed by the program, never by an LLM: acts are contiguous runs of the ARCH-STORY-01 order sized by word budget, and every judged Contested claim is placed in the turning-point act (the act before the closing act) — check: unit tests on `act_plan.rs`; no `LlmTask` reply carries an act's claim ids — cite: docs/architecture/story.rules.md:19
- **ARCH-STORY-10** [decided] If built, the act writer MUST make one LLM call per act with only that act's claims, their source chunks and the previous act's last turns, and MUST join the acts into one `Script` checked as a whole by `build_script`'s checks (citations, quotes, judged Contested cited, cast, beats); MUST NOT add a persisted artifact kind — check: `ArtifactKind` unchanged; joined-script test runs the whole-script checks — cite: crates/podling-core/src/stages/script.rs:270
- **ARCH-STORY-11** [decided] SHOULD log at `debug` the request's claim order (ids) and, if built, the act plan; SHOULD log at `info` each script's word ratio — check: `tracing` calls in `script.rs` — cite: crates/podling-core/src/stages/script.rs:134
